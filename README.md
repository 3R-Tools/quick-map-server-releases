# Quick Map Server — релізи

Сервер для **Quick Map**: облікові записи, проєкти на сервері зі спільним доступом, спільна робота в реальному часі, серверні тайли та адмін-консоль. Розгортається у себе одним `docker compose` — у локальній мережі, у закритому контурі або на публічному домені.

Сам Quick Map працює і без сервера; сервер потрібен лише для спільної роботи.

Вихідний код тут не публікується — у релізах лише готові до розгортання файли.

## Що в релізі

Остання версія: **[Releases](https://github.com/3R-Tools/quick-map-server-releases/releases/latest)**

| Файл | Що це |
|---|---|
| `quick-map-server-<версія>.zip` | тека для розгортання: `docker-compose.yml`, `.env.example`, `Caddyfile`, докладний `README.md` |
| `quick-map-api-<версія>.tar.gz` | образ API (для `docker load`) |
| `quick-map-web-<версія>.tar.gz` | образ вебчастини: клієнт Quick Map та адмін-консоль (для `docker load`) |
| `SHA256SUMS.txt` | контрольні суми файлів |

## Що потрібно

- Сервер з Linux і встановленими Docker та Docker Compose.
- Відкритий порт 80 (і 443, якщо є домен).

## Розгортання

1. Завантажте з релізу три файли: `quick-map-server-<версія>.zip` і два образи `.tar.gz`. Перевірити цілісність: `sha256sum -c SHA256SUMS.txt`.
2. Розпакуйте архів на сервері та перейдіть у теку `quick-map-server`.
3. Завантажте образи:

   ```bash
   docker load -i quick-map-api-<версія>.tar.gz
   docker load -i quick-map-web-<версія>.tar.gz
   ```

4. Створіть налаштування: `cp .env.example .env` і заповніть у `.env`:
   - `POSTGRES_PASSWORD` — пароль бази;
   - `JWT_SECRET` — довгий випадковий рядок (`openssl rand -base64 48`);
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — перший адміністратор;
   - `DOMAIN` — `:80` для локальної мережі або ваш домен (тоді сертифікат HTTPS отримується автоматично).
5. Запустіть: `docker compose up -d`.
6. Відкрийте `http://<адреса-сервера>/` — це Quick Map, який роздає сам сервер. Адмін-консоль: `http://<адреса-сервера>/admin/`.

Окрім двох образів Quick Map, потрібні образи PostgreSQL і Martin (їхні версії вказані в `docker-compose.yml`). З доступом до інтернету Docker завантажить їх сам під час запуску. У закритій мережі збережіть їх на машині з інтернетом (`docker pull`, потім `docker save`) і так само завантажте через `docker load`.

## Підключення з Quick Map

У застосунку: кнопка з іконкою бази даних у заголовку панелі → адреса сервера → вхід. Облікові записи створює адміністратор в адмін-консолі; публічної реєстрації немає.

У локальній мережі без HTTPS відкривайте Quick Map **з адреси самого сервера**: застосунок, відкритий з `https://`-сайту, не може звертатися до сервера по `http://` — це блокує браузер.

## Оновлення

1. Зробіть резервну копію (розділ «Backups» у `README.md` з архіву).
2. Завантажте файли нового релізу, виконайте `docker load` для обох образів.
3. Замініть `docker-compose.yml` і `Caddyfile` на нові; `.env` лишається ваш.
4. `docker compose up -d` — оновлення бази застосуються самі під час старту.

Резервні копії, тайли, вхід адміністраторів і розв'язання проблем описані в `README.md` усередині архіву.
